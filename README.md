# Tu pequeño refugio

App de Tareas y Productividad para estudiantes que también trabajan.

- **Integrantes** — Cristian Franchini y Sheila Villanueva.
- **Portafolio publicado** — Pendiente de agregar el enlace de GitHub Pages.
- **Demo** — Pendiente para la entrega final.

El repositorio contiene `index.html`, `css/` para el estilo, `img/` para las capturas WebP y `anexos/` para los PDF de evidencia. La entrega final puede incorporar la demo en `demo/` y añadir al sitio las tres secciones finales.

Para previsualizar, abrí `index.html` en el navegador. Para publicar, subí los archivos y carpetas a la raíz del repositorio público del equipo. En Settings → Pages, seleccioná Deploy from a branch, main y / (root). Agregá el enlace publicado a este README y comprobá el acceso sin iniciar sesión.
